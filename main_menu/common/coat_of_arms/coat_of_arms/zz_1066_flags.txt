# 1066 coats of arms — the cosmetic-upgrade batch (CoA research pass,
# 2026-07-29). The database is additive and key-merged: a country with no
# flag_definition list uses its TAG as the COA_KEY directly
# (flag_definitions/00_flag_definitions.txt:1), and when two files define
# the same key the LAST-LOADED file wins — hence the zz_ prefix
# (Basileia's stated rule, zz_br_flags.txt:1). A tag with no entry errors
# nothing: the template_lists generator synthesizes a religion-gated flag,
# which is why only these nine keys exist — the remaining 33 invented tags
# are DELIBERATELY left to the generator (taifa and Seljuk-client polities
# had no heraldry; anything invented would be no more historical). That
# list lives in verify_mod.py as _GENERATOR_OK; a new tag must join one
# side or the other or the harness fails.
